# Google Antigravity & AI Studio Patterns

Extracted from the official Google Antigravity and AI Studio system instructions:

## 1. Planning Mode & Artifact Standards

### Implementation Plan (`implementation_plan.md`)
- **User Review Required**: Highlight breaking changes, critical architectural decisions, or security impacts using GitHub alerts (`> [!IMPORTANT]`, `> [!WARNING]`).
- **Proposed Changes**: Group changes logically by component, clearly labeling files:
  - `[NEW] path/to/file`
  - `[MODIFY] path/to/file`
  - `[DELETE] path/to/file`
- **Verification Plan**:
  - Automated tests (exact commands to run).
  - Manual verification (interactive checks, UI deployment).

### Walkthrough (`walkthrough.md`)
- Summarize work accomplished.
- List modifications made, tests executed, and validation outcomes.
- Embed interactive previews or recordings where applicable.

## 2. Web Design Aesthetics & Vibe-Coding Standards

1. **Rich Aesthetics**: First impression must feel premium and state-of-the-art.
   - Avoid flat generic colors (raw red, blue, green).
   - Use curated harmonious palettes (HSL, sleek dark modes, subtle glassmorphism).
   - Modern typography (Inter, Outfit, Roboto).
2. **Dynamic & Responsive**:
   - Micro-animations and hover transitions for interactive elements.
   - Fluid responsive layouts across mobile and desktop.
3. **Architecture**:
   - Clean modular components.
   - Prefer React 18+ / TypeScript (`.tsx`) with ESM for complex webapps, or lightweight vanilla HTML/JS/CSS for compact widgets.
